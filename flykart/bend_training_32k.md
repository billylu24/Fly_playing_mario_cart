# 弯道训练：增加预算是否带来视觉反馈收益

## 预设实验

“之前训练不够”是合理假设；起步任务4096步没有视觉收益，不能证明这种模型无法学习视觉。本轮从头训练多起点弯道，预算32768决策，每8192决策评估一次，不根据中途成绩追加预算。

- run：`runs/bend_gain_32k_v1`；seed0；16环境，16序列批，BPTT32、上下文64，4 PPO epochs，其他优化超参数保持不变。
- 固定W，训练gain、encoder、actor和critic；三动作，repeat8。
- 训练起点：f540_center/left/right、f600_center/right，24帧扰动；每次reset独立均匀采样，各worker独立固定seed。
- 评估起点：f570_center/left/right；每起点3个动作采样seed5000–5002。每个阶段正常画面和固定首帧各9局；相同起点和动作采样种子，不输入RAM或起点ID。
- 目标checkpoint13；起点均checkpoint8；限1800帧，无进展600帧结束；零时间惩罚。重放前缀不计训练交互决策/奖励，实际模拟器工作量和墙钟包含这些重放。
- 保存每个阶段checkpoint，采用相同评估种子便于观察变化。这3个起点是验证集，不是最终独立测试集。

## 工程变化

接入任务工厂与worker，BendTask支持多起点随机reset，修复自动reset后episode起点ID可能被新起点覆盖的问题。保存前缀文件hash、实际任务限制与完整配置。原始Task行为保留。

运行命令（flykart目录）：

```bash
.venv-bench/bin/python -m training.train_gain --run runs/bend_gain_32k_v1 --task bend --budget 32768 --envs 16 --sequences 16 --target 13 --stall-frames 600 --action-set drive --repeat 8 --time-penalty 0 --eval-every 8192
```

## 解读规则

观察正常画面相对固定首帧的优势是否随训练扩大，而不只观察正常通过率。两者一起改善意味着可能主要学到更好的开环偏好；正常优于固定画面才是反馈价值的初步证据，还需要更多起点/种子及独立测试。

本轮同时更换为弯道任务、并行批大小和训练预算，因此不是纯粹对旧起步4096步实验做“只增加步数”的因果对照。相同弯道run内部的阶段比较更有参考价值；也不等价于已验证gain的独立贡献。

## 完成结果

32768决策、260859个计入episode的游戏帧、256次优化器更新，约461.5秒（7分42秒，含阶段评估），峰值allocated1762MiB，中位训练循环94.9决策/秒。重放前缀带来额外模拟器工作，不能把这个吞吐与旧起步环境直接比较。

完成390个训练episode，其中220次到达目标；64个rollout均有正奖励。W未变化，没有OOM/NaN；更新前重放偏差最大2.38e-7。由于并行批从128增到512，交互预算为此前8倍，但优化器更新数只从128增到256，即2倍；“练习更多”和“优化更多”要分别讨论。

| 决策数 | 正常画面 | 固定首帧 |
|---|---:|---:|
| 0（初始模型，同起点同seed） | 1/9 | 1/9 |
| 8192 | 1/9 | 1/9 |
| 16384 | 6/9 | 6/9 |
| 24576 | 2/9 | 2/9 |
| 32768 | 2/9 | 2/9 |

四个阶段每对9局的结束帧数、结束原因和进度也逐局一致，不仅仅是汇总通过率相同。最佳验证阶段是16384步，已保留独立 `step_16384.pt` 和 `best_validation.pt`；最终checkpoint不覆盖最佳checkpoint。

### 当前结论

更多训练曾提高短任务成绩，但后续回落；正常和固定画面始终一起变化。本次仍没有检测到持续视觉反馈收益。不能排除更长训练最终学到视觉，但已有证据不支持“单纯增加交互预算就足够”，更不能把训练episode成功率当作视觉学习率。

接下来优先做两个分开的诊断：固定同一任务和批大小增加更新预算；以及直接检查编码特征/读出对变化画面的敏感性，必要时用小型像素策略对照定位输入或connectome传播瓶颈。每项限定预算，不能同时改奖励、网络和训练范围后归因。9局验证样本太少，下一轮需增加评估种子，最终结论还需独立起点。

本轮训练已停止，无自动扩展到更长预算。

初始模型补充评估见 `initial_evaluation.json`，复现脚本 `tests/evaluate_bend_initial.py`。正常/固定均1/9。
