# 脑网络与CNN+GRU的监督学习对照

本实验完成架构×学习机制矩阵的监督学习一列。使用参考控制器动作作为标签，比较既有固定脑网络与标准可训练GRU，不进行PPO更新。推理时两种策略都只读84×84单帧灰度像素，不读RAM、参考动作、起点ID或奖励。

## 结论与下一步

**相同像素数据和明确动作监督足以让CNN+GRU学到持续视觉控制；当前固定脑网络在相同监督预算和优化配置下明显落后。** GRU三个种子均显示正常视觉优于固定首帧/时间表，确定性驾驶正常通过14/17、17/17、13/17。图模型相应为1/17、5/17、1/17，未显示正常视觉的稳定任务收益。

这使“只是PPO奖励太稀疏、critic干扰或探索不足”无法单独解释当前全部失败：本轮没有PPO、critic损失或探索问题，差距仍出现。另一方面，监督学习成功不证明GRU从零PPO一定成功；本轮没有完成PPO一列。

图模型第三个种子的训练平衡准确率达到46.1%、测试38.0%，说明并非完全无法学习；但它还没有得到可靠的视觉纠偏策略。应把结论限定为现有接口、动力学、训练范围与优化配置组合的学习效率较差，而不是所有生物连接图无法学习。两个架构的隐状态维数、可训练参数数目、当帧输入通路都不同，本实验不能单独归因到某一个因素。

下一步优先保持这份监督任务作为验收台：先比较结构化可训练视觉注入/输出适配与现有mod64接口，再单独检查内部更新频率和记忆动力学；每次只改一个因素，并继续要求正常视觉在闭环中优于固定画面。先让脑网络在明确监督下学到可用策略，再回到PPO，更能区分架构与RL机制。标准GRU监督模型保留为正对照，但不把绕过脑网络的成绩算成connectome收益。

## 预定设计

- 训练前在 `runs/supervised_architecture_v1/plan.json` 固定3个训练seed（0、1、2）、每组256次更新、序列批8、BPTT32、最多64步无梯度历史重建、每32决策重建一次状态。
- Adam，学习率0.0003、eps=1e-5，全局梯度裁剪1.0。损失为按训练集动作频次倒数加权的交叉熵，三类权重只从训练集计算。没有critic损失、熵正则或优势估计。
- 每个seed两组CNN结构和全部初始张量相同；样本序列抽样顺序相同，实际参与loss的样本呈现次数逐组断言一致。
- 图模型保留原GainPolicy：固定W、原mod64注入、可训练gain/encoder/actor；critic冻结且不参与损失。GRU模型复制相同CNN，接64维可训练GRUCell和线性三动作头。GRU能直接利用当次画面，是本次架构对照的一部分，并非“只去掉图而其他一切相同”。
- 每64更新计算独立验证轨迹上的正常视觉类别平衡准确率，最高者保存best，平分时取交叉熵最低者；不根据测试集选模型。所有种子均保留，不挑最好的一次报告。
- 训练集只有2184个不同标注决策，约5.4万次样本呈现是重复监督更新，不能当作新游戏交互。示范收集和闭环评估交互另外计算。

## 数据与任务

前缀450、480、540、600帧用于训练，510、570用于验证，495、555、615用于测试；每个前缀含center/left/right合法按键扰动。训练扰动12/24/36/48帧，验证24帧，测试18/30帧。控制器与像素策略都使用油门/油门左/油门右，repeat8；目标checkpoint13，无进展600帧结束，最多1800帧。

只按参考控制器成功且jumps=0筛选示范，筛选发生在模型训练前。完整候选与排除轨迹都保存在manifest和NPZ中。控制器失败不证明起点不可驾驶；本轮仅不把失败轨迹作为成功示范。

| 划分 | 候选/保留轨迹 | 保留决策数 | 直行/左/右标签数 |
|---|---:|---:|---:|
| 训练 | 48/43 | 2184 | 221/1227/736 |
| 验证 | 6/6 | 251 | 34/119/98 |
| 测试 | 18/17 | 795 | 76/488/231 |

三种划分两两之间的完全相同像素帧hash交集均为0。这只能排除精确帧重复，不能排除同赛道轨迹相近或收敛；本轮不代表独立赛道泛化。相邻帧按整条起点轨迹划分，没有随机拆帧。示范是确定性参考控制器自身访问状态，未用DAgger收集模型偏离后的纠错状态。

## 评估口径

离线报告普通准确率、每类召回率、混淆矩阵、三类召回率平均值（类别平衡准确率）和无类别加权交叉熵。固定单一动作的类别平衡准确率为1/3。

每个所选checkpoint在全部17个测试起点上做3种独立闭环输入模式：正常画面、固定本局首帧、纯时间表。每种模式包含1次greedy和动作采样seed8100–8102三次，分别汇报，不将随机采样成功与greedy混为一个指标。每模型204局，6模型总1224局。

纯时间表从第一条训练轨迹首帧生成225步概率，全体测试起点共用，不读当前起点画面。固定首帧保留起始信息；它们与正常视觉的差异比单看成功率更能反映视觉反馈价值。

为缩短墙钟，闭环评估在12个独立模拟器中运行，视觉模式按8列批量计算，每列隐藏状态和历史独立；每个模型首个测试起点的正常视觉seed8100与单环境评估器逐动作核对。训练和部分评估可能同时使用GPU，因此记录的墙钟时间不能直接用作严格架构吞吐比较。

## 实现与检查

新增 `training/supervised.py`，原训练器与模型代码未改。`tests/test_supervised.py` 对两架构验证训练序列的burn-in、padding与在线评估状态一致；反传均能到达CNN；同seed编码器初值hash一致。训练结束检查图W不变；评估前后检查所选checkpoint hash不变。

`plan.json`保存收集阶段源码hash；后续为闭环评估添加进程池以减少等待，没有改变训练超参数或数据选择。运行结束另保存最终源码hash，明确区分版本。

复现（flykart目录；collect要求输出目录不存在）：

```bash
.venv-bench/bin/python -m training.supervised collect
.venv-bench/bin/python tests/test_supervised.py
.venv-bench/bin/python -m training.supervised train --arch gru --seed 0
.venv-bench/bin/python -m training.supervised train --arch graph --seed 0
.venv-bench/bin/python -m training.supervised evaluate --arch gru --seed 0
.venv-bench/bin/python -m training.supervised evaluate --arch graph --seed 0
# 对seed1、seed2重复上述训练和评估
.venv-bench/bin/python tests/summarize_supervised.py
```

本轮不自动开始PPO一列；结论限于当前监督预算、优化器配置、示范覆盖与架构组合。图模型在这个条件下失败，不足以证明任何connectome架构都不可学习；监督离线成功而闭环失败也可能来自行为克隆的分布偏移。
