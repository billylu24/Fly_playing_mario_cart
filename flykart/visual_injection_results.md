# 可训练视觉注入接口对照

本轮只改变视觉注入的可训练性，保留原始CNN结构、固定W、gain、状态更新公式、脑网络读出和三动作控制。使用既有监督学习数据及其训练/验证/诊断测试划分，三个seed（0/1/2）各256次更新，批次8、BPTT32、历史64、学习率0.0003，与原图模型相同。没有PPO或新增奖励。

## 结论与后续方向

**这次可训练分组投影没有解决持续视觉控制问题。** 测试平衡准确率由旧接口36.2%变为36.4%，正常/固定首帧差异仍很小。正常视觉greedy通过数由7/51变为12/51，但新接口固定首帧16/51、纯时间表21/51均更高，不能将总体通过数上升解释为学会视觉；随机采样正常视觉也只有11/153，相比旧接口12/153没有改善。

三个新投影的参数确实改变，初值与旧接口等价，梯度和共享参数/训练呈现量检查均通过。第三个seed的分类表现有所提高，但正常视觉闭环0/17，说明弱的离线识别差异没有转化为有效纠偏。现有证据否定的是“仅加这层分组线性适配就足够”，没有排除更强的空间映射、特征预训练或输入归一化方案。

下一项建议转向独立动力学对照：在相同单帧输入和游戏repeat8下，比较每次动作前1/2/4次脑网络内部更新。这样可检查当前画面只能在后续动作时才到达读出的问题；内部更新数同时改变每决策的收缩与梯度传播，不能把结果只归因于延迟。先保持旧接口作为对照，避免同时叠加本轮改动；训练和评估均需采用相同内部步数，并保持相同监督预算/报告额外计算成本。另一项独立方向是输入到动作读出的局部梯度和可解码性，必要时再改记忆机制。上述动力学实验本轮尚未执行。

## 接口设计

原接口把64维视觉特征按神经元编号mod64分配。本轮根据视觉神经元的superclass与somaSide构造11组，每组增加一个64×64线性投影，参数化为I+Delta，Delta初始全0，共45056个新增参数。每个神经元仍读取其原来的通道位置，但可以从本组投影后特征中接收不同的通道组合。

这种设计允许不同类别/侧别使用不同的输入组合，同时使初始映射与旧模型等价。它并未建立真实视网膜拓扑，也没有取消组内按编号mod64的槽位分配；不能把一次否定结果泛化为所有视觉接口改造都无效。权重W仍全部为正且入边归一化，网络响应延迟和收缩性均未改变。训练gain和既有CNN/actor继续保留。

接口初始检查：全部共享模型tensor逐项相同，10步序列（含中途reset）前向最大logit误差1.86e-9；新投影梯度范数0.00314，CNN也收到有限梯度。正常训练和闭环评估复用上轮同一套代码。

## 对照与验证规则

- 复用上轮43条训练轨迹、6条验证轨迹、17条测试轨迹。每个seed的CNN初值、全部共享参数、数据hash和有效样本呈现数与原图基线核对。
- 每64步按验证集正常视觉平衡准确率选checkpoint，平分时按交叉熵；训练预算事先固定，不根据测试成绩追加。
- 每模型204局：17起点×正常/固定首帧/纯时间表×greedy及3个动作采样seed（8100–8102）。三模型共612局，另有3局单环境/批量评估器回归核对。
- 旧图模型和GRU成绩复用已保存的完整评估，不重复训练。新接口增加参数量，属于可训练性对照，不是参数量完全匹配的比较。
- 这里的测试集已经用于上一轮诊断，本轮是重复使用的诊断集，不是新独立测试。若下一步据此选择架构，仍需另外留出未用于设计的起点/路段。当前结果只代表同一赛道的短弯道任务。
- 训练中校验W不变；评估前后校验checkpoint文件hash不变；汇总时再次逐seed核对原共享初始tensor，并确认Delta初值为0。

## 文件与复现

代码为 `training/injection_experiment.py`，它复用supervised训练器并提供独立模型工厂；原model.py和supervised.py未修改。分组、计划、检查、训练与评估输出在 `runs/visual_injection_v1/`，数据只通过链接读取上一轮NPZ。

在flykart目录运行（prepare要求输出目录不存在）：

```bash
.venv-bench/bin/python -m training.injection_experiment prepare
.venv-bench/bin/python -m training.injection_experiment all
.venv-bench/bin/python tests/summarize_injection.py
```

也可用check、train --seed N、evaluate --seed N分别运行各阶段。train要求该seed输出目录不存在；本脚本不覆盖既有训练checkpoint。
